# 🔐 Secure VPC Architecture

## 📌 Overview

Built a secure AWS network ensuring no direct access to backend systems.

## 🏗️ Services Used

* VPC
* Public & Private Subnets
* Bastion Host
* NAT Gateway
* RDS

## 🔒 Security Features

* Bastion Host for controlled SSH access
* Private EC2 instances without public IP
* Database isolated in private subnet
* Strict security group rules

## ⚙️ Implementation Steps

1. Created VPC and subnets
2. Configured Internet Gateway & NAT Gateway
3. Launched Bastion Host
4. Deployed EC2 in private subnet
5. Setup RDS with restricted access
