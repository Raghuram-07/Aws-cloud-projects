# ⚡ Serverless Application on AWS

## 📌 Overview

Developed a fully serverless backend application using AWS services.

## 🏗️ Services Used

* AWS Lambda
* API Gateway
* DynamoDB
* S3 (Event Trigger)

## 🚀 Features

* Event-driven architecture
* No server management
* Pay-per-use cost model

## ⚙️ Implementation Steps

1. Created Lambda function
2. Integrated API Gateway
3. Created DynamoDB table
4. Configured S3 trigger
